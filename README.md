# LEADORA — نسخه MVP 0.5.0

سامانه وب فارسی سبک برای مدیریت پایه عملیات کسب‌وکار، مبتنی بر FastAPI و SQLite.

## قابلیت‌های پیاده‌سازی‌شده
- ثبت شرکت و ورود کاربر
- هش امن رمز عبور و نشست امضاشده
- محدودسازی تلاش‌های ناموفق ورود با پنجره ۱۵ دقیقه‌ای و ذخیره پایدار شمارنده‌ها
- اعتبارسنجی فیلدهای متنی پس از حذف فاصله‌های اضافی و سرآیندهای امنیتی HTTP
- جداسازی اطلاعات پایه کالا و مشتری بر اساس شرکت
- ثبت و مشاهده کالاها و موجودی
- نمایش هشدار قواعدمحور موجودی کم
- ثبت رویدادهای پایه و endpoint سلامت
- ثبت فاکتور و پرداخت جزئی با محاسبه مانده و دسته‌بندی سنی مطالبات
- ثبت هزینه‌های برنامه‌ریزی‌شده و محاسبه خروجی نقدی ۳۰ روزه قواعدمحور
- ثبت فرصت فروش و خلاصه قیف فروش بر اساس مراحل
- داشبورد شش ایجنت با اعلام صریح محدودیت داده و پیشنهادهای عملیاتی
- قالب CSV برای آماده‌سازی داده‌های فاکتور، هزینه و فرصت فروش
- ویرایش و حذف کالا و مشتری با کنترل مالکیت شرکت
- خروجی CSV کالاها و مشتریان، نسخه پشتیبان JSON مخصوص هر شرکت و نمایش رویدادهای اخیر
- کنترل‌های ویرایش/حذف و خروجی‌گیری در رابط فارسی
- رابط کاربری فارسی بازطراحی‌شده، واکنش‌گرا برای موبایل و دسکتاپ
- زیرساخت اولیه PWA: manifest، service worker، آیکون و راهنمای نصب
- Docker/Compose و گردش‌کار GitHub Actions برای بررسی کیفیت

## اجرای محلی
نیازمند Python 3.12 یا جدیدتر است:

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
سپس `http://127.0.0.1:8000` را باز کنید. برای محیط تولید، یک `LEADORA_SECRET` تصادفی و امن با حداقل ۳۲ نویسه تنظیم و `LEADORA_ENV=production` را فعال کنید.

## آزمون و استقرار

گردش‌کار GitHub Actions به‌صورت خودکار روی هر تغییر اجرا می‌شود و آزمون‌های Python، کامپایل، نحو JavaScript، اعتبارسنجی PWA و ساخت تصویر Docker تولید را بررسی می‌کند. [مشاهده وضعیت CI](https://github.com/gavad54/LEADORA/actions).

**وضعیت انتشار:** برنامه هنوز روی میزبان عمومی deploy نشده است. PWA برای نصب از مرورگر به HTTPS نیاز دارد؛ فایل‌های PWA به‌تنهایی سایت عمومی یا اپ اندروید بومی تولید نمی‌کنند.

## APIهای پایه ایجنت‌ها
- `POST/GET /api/invoices` و `POST /api/invoices/{id}/payments`
- `POST/GET /api/expenses`
- `POST/GET /api/opportunities`
- `GET /api/agents/overview` و `GET /api/agents/actions`
- `GET /api/import/template/{invoices|expenses|opportunities}.csv`

این مرحله قالب فایل و APIهای ثبت را فراهم می‌کند؛ بارگذاری مستقیم فایل CSV به پایگاه داده هنوز پیاده‌سازی نشده است. اتصال زنده به سرویس‌های بیرونی نیز در این نسخه فعال نیست.

## محدودیت‌ها
این نسخه MVP است، نه محصول نهایی سازمانی. سفارش‌گیری پیشرفته، حسابداری، پرداخت، اتصال زنده به سرویس‌های بیرونی، بازیابی رمز، نقش‌ها و مجوزهای پیشرفته، زمان‌بندی و بازیابی آزموده‌شده پشتیبان، ممیزی امنیتی مستقل و استقرار عمومی باید جداگانه تکمیل و بررسی شوند. تحلیل فعلی قواعدمحور است و ادعای مدل هوش مصنوعی ندارد. اقدام‌های حساس، ارسال پیام و جابه‌جایی پول به‌صورت خودکار اجرا نمی‌شوند.
