# LEADORA

نسخه MVP 0.3 — بسته پایه برای توسعه و آزمون.

## وضعیت پروژه
این مخزن میزبان کد و مستندات LEADORA خواهد بود. پس از بارگذاری فایل‌های منبع، اجرای آزمون‌ها و گردش‌کار GitHub Actions باید بررسی شود.

## اجزای نسخه
- برنامه Python و FastAPI
- رابط کاربری وب
- آزمون‌های امنیتی و جریان‌های API
- Docker و Docker Compose
- گردش‌کار CI
- مستندات معماری، ممیزی انتشار و تجاری‌سازی

## اجرای محلی
