# LEADORA — نسخه MVP 0.3

سامانه وب فارسی سبک برای مدیریت پایه عملیات کسب‌وکار، مبتنی بر FastAPI و SQLite.

## قابلیت‌های پیاده‌سازی‌شده
- ثبت شرکت و ورود کاربر
- هش امن رمز عبور و نشست امضاشده
- جداسازی اطلاعات پایه کالا و مشتری بر اساس شرکت
- ثبت و مشاهده کالاها و موجودی
- نمایش هشدار قواعدمحور موجودی کم
- ثبت رویدادهای پایه و endpoint سلامت
- رابط وب فارسی واکنش‌گرا
- Docker/Compose و گردش‌کار GitHub Actions برای بررسی کیفیت

## اجرای محلی
نیازمند Python 3.12 یا جدیدتر است:

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
سپس `http://127.0.0.1:8000` را باز کنید. برای محیط تولید، یک `LEADORA_SECRET` تصادفی و امن با حداقل ۳۲ نویسه تنظیم و `LEADORA_ENV=production` را فعال کنید.

## آزمون و استقرار
آزمون‌های محلی بسته آماده‌شده ۱۲ مورد موفق داشته‌اند. اجرای GitHub Actions برای نسخه فعلی هنوز در انتظار شروع/نتیجه است؛ تا اعلام نتیجه سبز، موفقیت CI تأیید نشده است. این مخزن هنوز روی میزبان عمومی deploy نشده است.

## محدودیت‌ها
این نسخه MVP است، نه محصول نهایی سازمانی. سفارش‌گیری پیشرفته، حسابداری، پرداخت، اتصال زنده به سرویس‌های بیرونی، بازیابی رمز، نقش‌های پیشرفته، پشتیبان‌گیری خودکار، ممیزی امنیتی مستقل و استقرار عمومی باید جداگانه تکمیل و بررسی شوند. تحلیل فعلی قواعدمحور است و ادعای مدل هوش مصنوعی ندارد.
