# معماری نسخه MVP

- **رابط کاربری:** صفحه وب فارسی در `app/static/index.html`.
- **API:** FastAPI در `app/main.py`.
- **ذخیره‌سازی:** SQLite با شناسه شرکت (tenant_id) در جداول کسب‌وکار.
- **ورود:** هش رمز عبور PBKDF2-HMAC-SHA256 و توکن امضاشده با HMAC.
- **کنترل کیفیت:** GitHub Actions برای کامپایل Python، آزمون API و بررسی نحو JavaScript.

## مرزهای فعلی
این نسخه قابلیت‌های پایه ثبت شرکت، ورود، کالا، مشتری و هشدار موجودی کم را دارد. سیستم حسابداری، پرداخت، اتصال‌های زنده به سرویس‌های بیرونی، بازیابی رمز، مدیریت نقش پیشرفته، پشتیبان‌گیری خودکار و استقرار عمومی در این MVP پیاده‌سازی نشده‌اند. قبل از استفاده با داده واقعی، بازبینی امنیتی و سیاست پشتیبان‌گیری ضروری است.
