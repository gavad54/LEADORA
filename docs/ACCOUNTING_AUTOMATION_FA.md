# LEADORA — ماژول حسابداری افزایشی
این تغییرها به‌صورت افزایشی به ساختار فعلی اضافه می‌شوند و جدول‌ها یا داده‌های قبلی را حذف نمی‌کنند. دفتر کل دوبل، کدینگ پایه، اسناد پیش‌نویس، تأیید انسانی، دفتر اسناد، تراز آزمایشی، سود و زیان پایه، ثبت پیشنهادی فروش/هزینه، کنترل مرجع تکراری و تنظیمات اتوماسیون پوشش داده می‌شوند. همه داده‌ها به tenant شرکت محدود هستند و رویدادهای مهم ثبت می‌شوند.

## محدوده و موانع باقی‌مانده
این نسخه معادل کامل سپیدار نیست و برای استفاده قانونی/تجاری نهایی محسوب نمی‌شود. گردش‌های کامل خرید و فروش متصل به فاکتورهای اصلی، انبار و بهای تمام‌شده، دریافت/پرداخت و مغایرت بانکی، چک، ارزش افزوده و مالیات، حقوق و بیمه، دارایی ثابت/استهلاک، بستن دوره، صورت‌های مالی کامل، تقویم شمسی و خروجی‌های قانونی هنوز نیازمند طراحی و آزمون هستند. اتصال واقعی به بانک یا سپیدار تنها با API رسمی و مجوز معتبر انجام می‌شود. ثبت قطعی خودکار بدون کنترل کاربر فعال نیست. پیش از داده واقعی، پشتیبان‌گیری و بررسی حسابدار/متخصص مالیاتی لازم است.

## آزمون‌ها
tests/test_accounting.py تراز سند، رد سند نامتوازن، جلوگیری از مرجع تکراری و جداسازی tenantها را می‌آزماید. ادعای موفقیت عملیاتی فقط پس از اجرای CI و آزمون محیط استقرار مجاز است.
