# LEADORA MVP — وضعیت انتشار

این نسخه یک MVP آزمایشی است، نه سامانهٔ آمادهٔ استفادهٔ حساس یا انتشار تجاری بدون بازبینی.

## امکانات فعلی
- ثبت شرکت و ورود کاربر
- تفکیک داده‌ها بر اساس شناسه شرکت در کالاها و مشتریان
- مدیریت پایه کالا و موجودی
- هشدار قواعدمحور موجودی کم
- ثبت رویدادهای پایه
- SQLite، رابط وب فارسی و بررسی سلامت API

## وضعیت آزمون خودکار
آخرین اجرای GitHub Actions در ۱۹ اکتبر ۲۰۲۶ موفق بوده است: ۶ آزمون پایتون، بررسی کامپایل پایتون و بررسی نحو جاوااسکریپت موفق شدند. سه اجرای قرمز اولیه در تاریخچه، مربوط به commitهای پیش از اضافه‌شدن آزمون‌های قابل اجرا هستند؛ سابقهٔ قدیمی GitHub همچنان قرمز می‌ماند.

آخرین اجرای موفق: https://github.com/gavad54/LEADORA/actions/runs/39294288744

## اجرای آزمایشی
Python 3.12+:
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
سپس به `http://127.0.0.1:8000` بروید. برای محیط تولید، متغیر `LEADORA_SECRET` را با مقدار تصادفی امن حداقل ۳۲ نویسه تنظیم کنید و `LEADORA_ENV=production` قرار دهید.

## محدودیت‌های انتشار
- قبل از استفاده واقعی باید بازبینی امنیتی مستقل، مدیریت بازیابی رمز، محدودسازی نرخ، پشتیبان‌گیری و سیاست حفظ داده تکمیل شود.
- تحلیل هوشمند فعلی صرفاً قواعدمحور است و ادعای مدل AI ندارد.
- این مخزن به‌تنهایی استقرار عمومی انجام نمی‌دهد؛ به میزبان و تنظیمات محیطی امن نیاز است.
