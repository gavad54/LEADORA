# مشخصات ادغام بازاریابی و رشد در LEADORA — 2026-11-19

## تصمیم محصول
LEADORA مالک تجربه عملیاتی کسب‌وکار، مشتری‌یابی، مدیریت سرنخ و گردش‌کارهای بازاریابی/رشد خواهد بود. بسته بازاریابی قبلی ARIA در LEADORA ادغام می‌شود. نام داخلی قبلی این بسته از UI، منو، API عمومی و نام‌گذاری محصول حذف می‌شود؛ نام تاریخی فقط در crosswalk خصوصی ممیزی باقی می‌ماند.

## وضعیت فعلی مخزن
مخزن gavad54/LEADORA یک سامانه وب فارسی مبتنی بر FastAPI و SQLite دارد. README شاخه main قابلیت‌های عملیاتی مشتریان، کالا، فاکتور، پرداخت جزئی، هزینه، فرصت فروش، کمپین، ورود CSV، بانک سرنخ‌ها، مشتری‌یابی زمان‌بندی‌شده و داشبورد قاعده‌محور را توصیف می‌کند. همان README تصریح می‌کند ارسال پیام/تماس بازاریابی و برخی اتصال‌های بیرونی تا زمان تنظیم API معتبر و مجوز فعال نیستند. این سند به‌تنهایی هیچ اتصال بیرونی یا ارسال واقعی را فعال نمی‌کند.

## وابستگی مشترک
- استودیوی تولید محتوای حرفه‌ای (ARIA-PROBLEM-MODULE-034) در ARIA/NEGAH باقی می‌ماند؛ LEADORA خروجی محتوای کمپین را از طریق connector مجاز دریافت می‌کند.
- LEADORA یازده شناسه اختصاصی دریافت می‌کند؛ این سرویس محتوایی وابستگی است و مالکیت اجرایی آن منتقل نمی‌شود.

## تجربه کاربری مقصد
1. مرکز بازاریابی: برنامه کمپین، هدف، بودجه مفروض، مخاطب و تقویم.
2. مدیریت سرنخ: منبع، رضایت، وضعیت، مسئول، مرحله قیف و تاریخچه پیگیری.
3. ارتباطات مجاز: پیش‌نویس پیام، بازبینی، صف انتشار و ثبت نتیجه؛ ارسال بیرونی تا اتصال مجاز و تأیید کاربر غیرفعال می‌ماند.
4. مدیریت شبکه اجتماعی: تقویم محتوا، نسخه‌ها، مالک تأیید و وضعیت انتشار؛ اتصال هر شبکه نیازمند OAuth/API رسمی و مجوز.
5. سلامت و نگهداشت مشتری: شاخص‌های توضیح‌پذیر، ریسک ریزش و آمادگی تمدید با منبع داده و محدودیت مشخص.
6. تحلیل کمپین: هزینه، سرنخ، تبدیل و بازده با تعریف روشن KPI و تفکیک مقدار واقعی از تخمین.
7. گزارش رشد: قیف، عملکرد کانال و اقدام بعدی پیشنهادی.

## مرزهای فنی و داده
- ماژول بازاریابی باید از هسته LEADORA و نقش‌های شرکت/tenant استفاده کند؛ داده مشتری شرکت‌ها نباید میان tenantها نشت کند.
- پیام‌رسانی باید رضایت، opt-out، محدودیت نرخ، لیست منع تماس و audit log داشته باشد.
- هیچ کمپین یا پیام عمومی بدون preview و تأیید صریح مسئول مجاز ارسال نمی‌شود.
- توکن سرویس‌های بیرونی در secret store نگهداری می‌شود و هرگز در UI، log یا repository قرار نمی‌گیرد.
- تحلیل بازده بازاریابی تنها یک پیاده‌سازی مالک دارد؛ ARMIN MARKET در صورت نیاز فقط داده‌های بازار مجاز را از API دریافت می‌کند.
- حسابداری/ERP/دفترکل در دامنه این مهاجرت نیست. قابلیت‌های مالی موجود LEADORA تا ممیزی و تصمیم جداگانه حفظ می‌شوند؛ این انتقال مجوز حذف یا تکثیر قابلیت‌های ARIANA نیست.

## گیت‌های انتقال
1. افزودن manifest و crosswalk بدون تغییر شناسه‌های مبدا.
2. بررسی تکرار با کمپین‌ها و CRM فعلی LEADORA.
3. پیاده‌سازی backend/API و migration قابل برگشت.
4. تست tenant isolation، مجوزها، رضایت و opt-out.
5. اتصال پیام‌رسانی و شبکه اجتماعی فقط با API رسمی، OAuth و مجوز مالک حساب.
6. تست ارسال در محیط sandbox و جلوگیری از ارسال ناخواسته.
7. تست KPI و انتساب با داده آزمایشی و واقعی جداگانه.
8. CI، آزمون end-to-end، backup/restore و بررسی امنیت قبل از فعال‌سازی تجاری.
